# 🧭 Vazhikatti 2.0 – Essential Places Finder

## 📌 About the Project

**Vazhikatti 2.0** is a simple, interactive map-based web application designed to help users find essential places easily. It provides a Quick Finder interface that allows users to search for important facilities such as hospitals, public toilets, hotels, pharmacies, ATMs, and restaurants.

The project is developed using HTML5, CSS3, and JavaScript without depending on external map websites or mapping APIs.

## 🎯 Objectives

- Make essential places easier to find.
- Provide a simple and user-friendly interface.
- Allow users to search and filter places quickly.
- Display locations using a custom, interactive map interface.
- Demonstrate frontend development and JavaScript event handling.

## ✨ Features

- **Quick Finder:** Select a category to view matching places.
- **Search Functionality:** Search places by name, category, or address.
- **Interactive Map:** Display sample locations as clickable markers.
- **Place Details:** View the name and address of a selected place.
- **Responsive Design:** Supports desktop and mobile screens.
- **Standalone Operation:** Runs directly in a web browser without external map services.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select a Quick Finder category or search for a place.
5. Click a map marker or the View button to inspect a place.

No package installation or API key is required for the current demo.

## 🧩 JavaScript Events Used

- `click` – Select categories and map markers.
- `submit` – Process the search form.
- `keydown` – Clear the search field when Escape is pressed.

## ⚠️ Limitations

- The map is a custom visual demonstration, not a real geographic map.
- The included places and positions are sample data, not verified real-world locations.
- The application does not currently provide live navigation or automatic nearby-place discovery.
- The current version does not store user-submitted places in a shared database.
